# תכלת חשבונאות חכמה — כלי אוטומציה

מאגר כלים לאוטומציה של תהליכים חשבונאיים עבור משרד תכלת חשבונאות חכמה בע"מ.

## הכלים

### אוטומציה לסאמיט
- **sumit_tiyuk.py** — הגשת מסמכים אוטומטית בפלטפורמת סאמיט דרך כרום, כולל טיפול במודלים, כפילויות וגלילה וירטואלית
- **הקפאת_תיקים.py** — ניהול הקפאת תיקי לקוחות עם ממשק גרפי, עמודת סוג עוסק צבעונית ושמירת מצב סימון

### ייבוא שכר
- **movein_server.py** — ייבוא קבצי MOVEIN.DAT ממשכורת (מסכורשת) לסאמיט, עם התאמת חברות לפי מספר עוסק ושמירת הגדרות

### טפסים ואישורים
- **טופס 6101** — מילוי טופס ביטוח לאומי 6101 (דין וחשבון רב-שנתי) על גבי הסריקה המקורית
- **אישור לפול** — הפקת אישור ביקורת הצהרה בדבר אי ניכוי הוצאות אופנוע
- **הצהרת הון (טופס 1219)** — ריכוז אישורים ודוחות לקוחות לצורך הצהרת הון מקוונת

### מעקב לקוחות
- **מעקב_דיווחים.xlsx** — קובץ מעקב דיווחי לקוחות עם פאנל ניווט מהיר
- **ווידג'ט ניהול לקוחות** — כלי אינטראקטיבי עם שמירה מתמידה ועריכה מוטמעת
